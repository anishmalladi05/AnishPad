# AnishPad
I made this Macropad because I wanted one that was more customizable then my last, which only had 4 buttons. That time, the rotary encoder got the better of me, so I wanted to successfully put one in this time, which I did!
<br></br>
A 5 key, 1 rotary encoder, and 128 x 32 oled display macropad.

# To Flash:
Put the microcontroller in bootloader mode. (Hold reset, double press boot, release reset)
<br></br>
Plug into computer
<br></br>
Drag UF2 file into microcontroller
<br></br>


Replace boot_out.txt with boot_out.txt in my gihub repo under CIRCUITPY FILES
<br></br>
Replace code.py with code.py from my repo
<br></br>
Add boot.txt from my repo
<br></br>
Add boot.py from my repo
<br></br>

It should start working!
