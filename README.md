# AnishPad
A 5 key, 1 rotary encoder, and 128 x 32 oled display macropad.


# Bill of materials:
5x MX CHERRY SWITCES
1x 128x32 OLED panel (needs to allow for 5v)
5x Keycaps (Can buy own, or 3d print files are in the CAD folder)
1x SEEEDUINO XIAO RP2040
1x Ability to solder
1x EC11 Push button rotary encoder (the one wihtout the PCB attached)
1x PCB (found in PCB files)
1x UCB-C cable to connect to device
1x Coding skills (only if you want to customize or make it work for windows)
1x 3D printer
